# Scrambling for Dollars — Replication Code

Replication code for **"Scrambling for Dollars: International Liquidity, Banks and Exchange Rates"** by Javier Bianchi, Saki Bigio, and Charles Engel.

## Repository layout

```
Filtering/                        MATLAB / Julia estimation and figure pipeline
  main_filter.m                   Baseline particle filter for σ shocks (produces RW_shock.csv)
  main_filter_DW.m                Joint FF / DW filter variant
  main_robustness.m               Robustness sweeps (η, ι, ploss)
  estimate_params_4d.m            4-D parameter estimation (η calibration)
  estimate_params.m               Baseline 3-D estimation
  estimate_robustness_iota.m      Robustness — ι grid
  estimate_robustness_ploss.m     Robustness — ploss grid
  run_estimate_5d.m               5-D estimation wrapper
  compute_data_moments.m          Moments used by objective
  markov_estimation.jl            Julia regime-switching MLE (reads RW_shock.csv → MS_sigma_us_prob.csv)
  compare_filters.m               Leontief vs. Cobb-Douglas comparison
  load_data.m                     Reads Filtering/data/LFX_datainputs.xlsx
  functions/                      Model primitives (params, moments, steady state, χ operators)
    chi/                          Marginal / expectational χ operators
  plotting/                       plot_regimes.m, plot_baseline.m, plot_paper_figures.m, ...
  utils/                          exportfig, suptitle
  data/                           Small input data + reference outputs for plotting
    LFX_datainputs.xlsx           Raw data workbook (all series)
    LFX_data*.mat, calibration.mat   Precomputed loads
    MS_params.csv, MS_sigma_us_prob.csv   Current Markov estimates (regenerated by Stage 2)
    filter_comparison_*.mat, robustness_*.mat   Reference outputs (regenerated by pipeline)

Nonlinear Model/                  Steady-state and calibration of the full nonlinear model
  main_LFX.m                      Solves the 2-country nonlinear system
  feqm.m, feqm_vec.m              Equilibrium equations
  feqm_calibrate_fixed_sigma.m    Calibration with σ fixed at Markov ergodic mean
  LFX_params_cd_v3.m              Baseline Cobb-Douglas parameters (λ synced with Filtering)
  tauchen*.m                      Grid discretization utilities
```

## Pipeline

The results in the paper are produced end-to-end by:

| Stage | Script | Reads | Writes |
|-------|--------|-------|--------|
| 1 | `Filtering/estimate_params_4d.m` | `data/LFX_datainputs.xlsx` | Calibrated `θ`, `η`, model params |
| 2 | `Filtering/main_filter.m` | Stage 1 params, `data/LFX_datainputs.xlsx` | `Filtering/RW_shock.csv` |
| 3 | `Filtering/markov_estimation.jl` | `Filtering/RW_shock.csv` | `data/MS_sigma_us_prob.csv`, `data/MS_params.csv` |
| 4 | `Filtering/main_robustness.m` | Stage 1–3 outputs | `data/robustness_iota.mat`, `data/robustness_ploss.mat` |
| 5 | `Filtering/plotting/plot_regimes.m`, `plot_baseline.m`, `plot_robustness.m` | Stage 2–4 outputs | Figures |
| 6 | `Nonlinear Model/main_LFX.m` | `LFX_data2.mat`, `Z_im_{us,eu}.mat` | Table 4, steady-state figures |

Model variant (Leontief vs. Cobb-Douglas χ) is selected inside `main_filter.m`:

```matlab
model_variant = 'leontief';  % or 'cobb_douglas'
```

## Requirements

- **MATLAB** R2021b+ (uses `readtable`, `readmatrix`, name-value struct init). No toolboxes strictly required for the filter, but `Optimization Toolbox` (`fsolve`) is needed for calibration and `Statistics and Machine Learning Toolbox` speeds up simulation.
- **Julia** 1.9+ with `MarketData`, `CSV`, `DataFrames`, `StatsBase`, `Optim`, `Distributions`. Install with:
  ```julia
  using Pkg; Pkg.add(["CSV","DataFrames","StatsBase","Optim","Distributions"])
  ```
- **Python** 3.10+ (only for auxiliary plots): `pandas`, `numpy`, `matplotlib`. Optional.

## Running the pipeline

From MATLAB, from repository root:

```matlab
cd('Filtering')
run('estimate_params_4d.m')      % Stage 1: calibrate η
run('main_filter.m')              % Stage 2: filter σ shocks
```

From a shell:

```bash
cd Filtering
julia markov_estimation.jl        % Stage 3: Markov regime estimation
```

Back in MATLAB:

```matlab
run('main_robustness.m')          % Stage 4
run('plotting/plot_paper_figures.m')  % Stage 5

cd('../Nonlinear Model')
run('main_LFX.m')                 % Stage 6
```

## Data

The single raw-data workbook is `Filtering/data/LFX_datainputs.xlsx`. Source series:
- Exchange rates, forward rates, policy rates: Federal Reserve H.10, Bloomberg
- CIP deviations: Du–Schreger–Verdelhan dataset (Wu tab)
- TED spreads, EFFR: FRED
- Bank liquidity ratios (HQLA / assets): FEDS Notes, monthly-interpolated

Data provenance and sheet-by-sheet notes are documented in the `Documentation` tab of the workbook. No external downloads are required to reproduce the results.
